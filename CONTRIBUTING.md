# Contributing

Thank you for your interest in improving hybris-boot.

This project is based upon the original work of the Mer and Jolla communities.

Please respect the existing architecture and coding style whenever possible.

---

## Guidelines

- Keep commits focused.
- Prefer extending existing code.
- Avoid unnecessary rewrites.
- Preserve formatting where practical.
- Document behavioral changes.
- Test before submitting.

---

## Copyright

Do not remove existing copyright notices.

If substantial new work is contributed, append new copyright information while preserving existing authorship.

---

## Coding Style

Follow the surrounding code.

Avoid unrelated formatting changes.

Keep patches readable.

---

## Pull Requests

Good pull requests are:

- focused
- documented
- tested
- easy to review

Large refactoring should be discussed before implementation.

---

## Project Philosophy

This project modernizes hybris-boot.

It does not attempt to replace its architecture.

Preserving compatibility with upstream remains an important objective whenever practical.
