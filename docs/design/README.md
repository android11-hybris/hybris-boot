# Design Documents

This directory contains the engineering documentation for the Android 11+
modernization of hybris-boot.

Unlike PROJECT.md and ROADMAP.md, these documents describe **how** the
boot framework works and the technical decisions behind its implementation.

These documents should evolve alongside the code.

## Documents

ANDROID11_BOOTFLOW.md
    Android 11+ boot architecture.

ARCHITECTURE.md
    High-level modernization design.

VENDOR_BOOT.md
    vendor_boot image layout and design.

BOOT_IMAGE_SELECTION.md
    Detecting the device boot architecture and selecting the correct image set.

FIRST_STAGE_INIT.md
    Android first-stage init compatibility.

DYNAMIC_PARTITIONS.md
    Support for super and logical partitions.

PIXEL5A.md
    Reference implementation notes for barbet.

RESEARCH.md
    Engineering notebook and collected references.
